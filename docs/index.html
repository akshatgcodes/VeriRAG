RAG answers cite sources. Nobody checks them.

VeriRAG breaks every answer into atomic claims and has a dedicated fact-checking model test each claim against every retrieved source. You see exactly which sentences are grounded, which cite the wrong paper, and which the model made up. It runs entirely on free, open-source models.

Pipeline

How it works

Four stages. The verifier is a separate model, because an LLM grading its own answer shares the blind spots that produced the error.

Retrieve

BM25 and BGE-M3 dense search, fused with Reciprocal Rank Fusion, then reranked by bge-reranker-v2-m3.

Generate

Qwen3 writes an answer with numbered citations, locally via Ollama or on the Groq free tier. It can say "I don't know".

Decompose

The answer is split into atomic, self-contained claims, each tied to its sentence and citations.

Verify

MiniCheck scores every claim against every source, which separates a hallucination from a wrong citation.

Design

Engineering decisions

Why a separate verifier instead of asking the LLM to check itself?

An LLM grading its own answer shares the blind spots that produced the error. A small classifier trained for grounding is deterministic, cheap to run and can be benchmarked on its own.

Why score each claim against every source, not just the cited one?

It separates two different failures. A claim no source supports is a hallucination. A claim another source supports is a citation error, and VeriRAG can name the right source.

Why RRF to merge BM25 and dense results?

BM25 scores and cosine similarities live on different scales. Reciprocal Rank Fusion only uses ranks, so it needs no weight tuning and still rewards chunks both retrievers agree on.

Why a sentence window for the NLI baseline?

NLI models are trained on short premises and truncate at 512 tokens. Scoring 3-sentence windows and taking the maximum keeps the premise in the range the model was trained on.
