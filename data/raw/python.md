# Python (programming language)

Python is a high-level, general-purpose programming language created by Guido van Rossum. Van Rossum began working on Python in the late 1980s as a successor to the ABC language, and the first version, Python 0.9.0, was released in February 1991.

The language is named after the British comedy group Monty Python, not after the snake. Python's design philosophy emphasizes code readability, and it uses significant indentation to delimit blocks of code.

Python 2.0 was released in October 2000 and introduced features such as list comprehensions and a cycle-detecting garbage collector. Python 3.0 was released in December 2008. It was a major revision that was not completely backward-compatible with earlier versions. Python 2 reached its end of life on January 1, 2020, after which it no longer received security patches.

Van Rossum served as the project's "Benevolent Dictator For Life" until he stepped down from the role in July 2018. Python is now governed by a five-member steering council elected by the core developers.
